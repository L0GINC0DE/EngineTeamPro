C:/Unity/EngineTeamPro 프로젝트의 2D 플랫포머 개발을 이어서 진행해줘.

먼저 적용 가능한 프로젝트 지침과 아래 인계서를 읽어줘.
C:/Unity/EngineTeamPro/docs/antigravity-platformer-handoff.md

사용자가 기본 이동과 점프의 실행을 확인한 상태야. 설계 전체를 한꺼번에 구현하지 말고, 현재 코드를 확인해서 작은 작업 단위로 직접 구현하고 검증해줘.

각 작업을 시작할 때는 다음을 짧게 설명해줘.
1. 프로토타입의 어느 부분인지
2. 이번에 할 작업과 이유
3. 수정할 파일이나 씬
4. 완료를 확인할 기준

첫 작업은 AgentMovement의 물리 처리 시점을 통일하는 것이야.
CalculateAirTime과 ApplyExtraGravity 호출을 FixedUpdate로 옮기고, 공중 시간 누적에 Time.fixedDeltaTime을 사용해줘. 기존 이동·점프와 Inspector 설정은 유지하고, 비어 있는 Update를 제거해줘. 이번 작업에 발사·무기·옷장 전체를 함께 넣지는 마.

작업 전에 git status와 관련 diff를 읽고 사용자 변경을 보존해줘. 이미 정리된 Canvas를 다시 만들지 말고, 남은 씬 오류가 검증을 막으면 현재 상태를 확인해서 필요한 범위만 정리해줘.

계획은 실제 코드와 플레이 결과에 따라 바뀔 수 있어. 변경 이유와 영향을 설명하고, 작업마다 구현 결과·실제로 수행한 검증·미검증 내용을 구분해서 보고해줘. 일반적인 구현 선택마다 승인을 반복해서 묻지 말고 진행하되, 게임 규칙을 크게 바꿔야 하는 경우에는 먼저 알려줘.

첫 작업을 마친 뒤 인계서의 진행 기록을 갱신하고 다음에 할 가장 작은 작업 하나를 제안해줘. 실제 실행하지 않은 내용을 통과했다고 표현하지 마.
