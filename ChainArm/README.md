# 산나비 · 사슬팔 액션

`sanabi-chain-arm.html`을 Chrome 또는 Edge에서 열면 바로 플레이할 수 있습니다. 인터넷, 설치, 서버가 필요하지 않습니다. 이 HTML 파일 하나만 복사해도 실행됩니다. 키보드·마우스용입니다.

| 조작 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 지상 즉시 이동·정지·반전. 사슬을 잡으면 회전된 몸체 기준 왼쪽/오른쪽 보기 및 빠른 스윙 반전 |
| 좌클릭 유지 | 청록색 벽·천장에 사슬 고정 |
| 좌클릭 해제 | 사슬 해제, 관성 유지 |
| Shift 또는 우클릭 | 사슬을 유지하며 플레이어가 현재 바라보는 방향으로 대시 |
| 방향 입력 없이 대시 | 마지막으로 바라본 몸체 기준 좌우 방향을 유지해 대시 |
| W / S | 사슬 감기·풀기, 벽 등반 |
| Space | 점프, 벽 차기, 사슬 해제 도약 |
| R / 1~4 | 체크포인트 복귀 / 구간 선택 |
| H / Esc | 조작 안내 표시 / 일시정지 |

처음에는 D로 조금 이동한 뒤 위쪽 청록색 천장을 좌클릭으로 잡으세요. D를 유지하면 오른쪽으로 스윙합니다. 캐릭터가 올라갈 때 Shift를 누르면 사슬에 매달린 채 빠르게 회전합니다. 분홍 화살표가 대시 직후 속도 방향입니다. 사슬을 놓고 날아가려면 좌클릭을 해제하세요.

지상에서는 A/D를 놓는 즉시 수평 속도가 0이 되며, 반대 키를 누르면 즉시 방향이 바뀝니다. 착지한 순간에도 잔여 수평 속도를 없앱니다. 공중의 사슬 스윙과 의도적인 대시 추진력은 유지됩니다.

훅이 걸리는 순간 몸체의 위쪽 축을 사슬 선에 즉시 맞춥니다. A는 회전한 몸체의 왼쪽, D는 오른쪽을 바라보게 합니다. 이 기준은 고정점의 위·아래·옆 어디에 있어도 같습니다. 시선은 키 입력 즉시 바뀌며, 스윙 속도는 강한 제동으로 빠르게 반전합니다. 키를 놓아도 마지막 시선은 유지되고 스윙 관성은 자연스럽게 이어집니다. 사슬이 느슨해져도 같은 몸체 기준을 사용합니다.

스윙 중에는 몸체 회전이 현재 사슬 선에 지연 없이 맞으며, 눈·사슬팔 표시·스카프·잔상도 함께 돌아갑니다. 사슬이 연결된 동안에는 지면에 닿아도 이 회전 기준을 유지합니다. 사슬을 해제하면 비행 방향으로 기울고, 사슬 없이 착지하거나 벽에 매달리면 바로 섭니다. 충돌 판정은 기존의 원형을 유지합니다.

사슬이 연결된 상태에서만 대시할 수 있습니다. 대시 방향은 몸체 회전과 시선으로 결정되고, 마우스나 남은 이동 속도가 방향을 바꾸지 않습니다. 눈이 보는 방향·분홍 화살표·대시 시작 방향이 일치합니다. 대시로 사슬의 고정점이나 길이는 바뀌지 않습니다. 새 사슬 연결 또는 새 착지로 대시가 충전됩니다. A와 D를 함께 누르면 마지막에 누른 키를 우선합니다. 같은 키를 계속 누르면 대시 속도를 보존하고, 새로 반대 키를 누르면 대시 직후에도 빠른 방향 전환이 가능합니다. 붉은 장갑에는 연결할 수 없고, 붉은 레이저에 닿으면 체크포인트로 돌아갑니다.

첨부 원본의 네 구역, 드론, 스카프·잔상·화면 흔들림 연출을 기반으로 만든 팬 조작 프로토타입입니다. 원작의 물리를 그대로 복제한 것은 아닙니다.

개발 확인: `node ChainArm/verify.cjs` (Node.js 필요). 플레이에는 Node.js가 필요하지 않습니다.
