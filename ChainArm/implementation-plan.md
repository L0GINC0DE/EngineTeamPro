# 사슬팔 HTML 제작 계획

사용자가 정정한 조작: 훅이 걸리는 순간 사슬 선에 회전을 즉시 일치시킨다. A/D는 이 몸체 회전을 기준으로 왼쪽/오른쪽을 바라보게 하며, 대시는 항상 그 시선 방향으로 나간다. 무입력 시 마지막 시선을 유지한다. 회전·시선·스윙 입력·대시·미리보기의 기준을 통일한다. 사슬 유지와 빠른 스윙 반전, 지상 즉시 정지·즉시 반전도 보존한다.

- [x] 첨부 HTML의 코스·그리기·효과를 보존하고 외부 CSS와 폰트 의존성을 제거한다. 결과물은 `sanabi-chain-arm.html` 하나다.
- [x] 접선 속도를 직접 조절해 사슬 각도에 따라 입력의 힘이 약해지는 문제를 해결한다. 반대 입력에는 강한 제동을 적용한다. 키를 유지하면 회전 지시가 고정점 높이를 지나며 자동으로 뒤집히지 않는다. 키를 놓으면 스윙 관성을 유지한다. 명시적인 반대 입력은 대시 직후에도 적용한다.
- [x] 지상 이동·반전·정지는 즉시 적용하고, 착지 순간에도 잔여 수평 속도를 없앤다.
- [x] 몸체·눈·사슬팔 표시·스카프·잔상을 사슬 각도에 즉시 맞춘다. 연결 이벤트와 매 물리 스텝 종료 시 회전을 갱신한다. 사슬이 연결된 상태에서는 지상에서도 이 기준을 유지한다. 사슬 없이 착지하거나 리스폰하면 바로 세운다. 충돌 모양은 유지한다.
- [x] 동일한 방향 계산을 대시와 미리보기에 사용한다. 좌우 동시 입력은 마지막 입력을 우선한다. 창 이탈 시 입력을 초기화하고 일시정지한다.
- [x] 240Hz 고정 물리로 고속 충돌을 검증한다. 점프 버퍼, 벽 이탈, 리스폰 상태를 점검한다.
- [x] 실제 HTML의 JS를 이용해 방향·가속·관성·충돌·프레임률 검사를 실행한다. 브라우저에서 오프라인 로드와 마우스·키보드 플레이를 확인한다.

Unity 프로젝트 파일은 변경하지 않는다. 별도 서버나 설치 없이 파일을 열어 실행한다.

현재 수정본 검증: `node ChainArm/verify.cjs --render-pose` 35개 검사 통과. 접선 대시 72가지에서 몸체의 시선·화살표·발사 방향 일치를 검증했다. 훅 연결과 키 입력 이벤트에서 즉시 회전·시선 갱신, 물리 스텝 후 회전 오차 없음, 지상 연결 상태의 회전 유지, 상하좌우 고정점에서의 몸체 기준 방향, 무입력 시 시선 유지도 검사했다. 스윙 반전 56가지에서 최대 83ms. 지상 미끄러짐 제거·시작 구간 연결 플레이·30/60/144Hz 일치·전체 회전·스카프·잔상 검사도 통과했다. 실제 게임 그리기 코드를 별도 캔버스로 실행한 rotation-preview.png를 생성했다. 브라우저 미리보기는 이 환경의 로컬 파일 접근 제한 때문에 이번 수정에서는 다시 열지 않았다.
